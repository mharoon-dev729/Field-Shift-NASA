# AI Usage Disclosure — Field Shift

This project is an individual entry to the NASA Space Apps Challenge 2026. Because AI assistance was used
throughout Phase 1, it is documented explicitly and honestly. Judges and reviewers should be able to see
exactly what was machine-assisted and what was verified by a human or by a live system.

---

## 1. What AI was used for

| Area | AI assistance | Human/tool verification |
|---|---|---|
| Environment inspection | Ran shell probes, read outputs | Outputs are reproducible from the commands in PROGRESS.md |
| PDF extraction | Chose `pdftotext -layout`, read the 161 extracted lines | Extracted text retained and quoted; commands recorded |
| Challenge research | Web search for the official brief and resource guidance | Primary source is the official challenge page + supplied PDF |
| Data-source audit | Drafted the 15-field register from the resource PDF plus prior knowledge of each product | **Every claim of coverage was checked against known product documentation; every "usable at pilot" verdict is a reasoned classification** |
| Live data verification | Wrote and ran the `curl`/Node probes | All responses real, recorded verbatim in the register's Appendix A |
| Pilot selection | Compared candidate districts | Justified from published Punjab CRS statistics and a peer-reviewed crop-share analysis |
| Documents | Drafted PRD, architecture, engine spec, contracts, schema, test strategy | Human review required before implementation; open questions listed in DECISIONS_LOG |
| Scaffold | Wrote the workspace structure and health endpoint | Typecheck and build executed locally (see PROGRESS verification block) |

## 2. What AI was explicitly **not** allowed to do

- **Invent observations.** No NASA, soil, or agronomic value in this project was generated. Every number in
  the documents is either quoted from a live API response (with the command that produced it) or cited to a
  named document.
- **Invent thresholds as fact.** The 35 °C/40 °C heat thresholds and all component weights are marked
  `provisional` in code and in the UI. Where no source exists, the parameter is `TO-VERIFY` or `NULL`.
- **Write the runtime explanations.** The product generates explanations from deterministic templates, not
  from an LLM. This is decision D-11.
- **Claim verification that did not happen.** Numbers taken from search extracts of PDFs are labelled as
  snippet-derived, with an explicit instruction to confirm page-level wording in Phase 2.

## 3. Claims in this documentation that a reviewer should re-check

These are honest weak points, listed so nobody has to discover them:

1. **Crop calendar dates** were taken from search extracts of Punjab CRS/PAU/AARI documents, not from a full
   page-by-page read. Each is attributed to the specific document that states it.
2. **District statistics** (wheat area 612,000 acres; production 939,000 t; cotton 58,000 acres) come from
   the cited CRS/MNFSR tables as surfaced in search results.
3. **Water-demand classes and irrigation requirements** are *not* established. They are `NULL`/`TO-VERIFY`.
4. **NDVI tile geometry** was not successfully derived (one 400 response); SMAP and IMERG tiles were verified.
5. **Direct SMAP/IMERG numeric extraction** is unverified — no Earthdata credential was configured.

## 4. Reproducing the verification

```bash
# PDF text
pdftotext -layout "reference/Resources of NASA Data.pdf" -

# NASA POWER (no key)
curl "https://power.larc.nasa.gov/api/temporal/daily/point?parameters=T2M,PRECTOTCORR,GWETROOT,ALLSKY_SFC_SW_DWN,RH2M&community=AG&latitude=31.4187&longitude=73.0791&start=20250601&end=20250605&format=JSON"

# Climatology
curl "https://power.larc.nasa.gov/api/temporal/climatology/point?parameters=T2M,PRECTOTCORR&community=AG&latitude=31.4187&longitude=73.0791&format=JSON"

# Soil
curl "https://rest.isric.org/soilgrids/v2.0/properties/query?lon=73.15&lat=31.35&property=clay&property=sand&property=soc&property=phh2o&depth=0-5cm&depth=5-15cm&value=mean"

# NASA imagery tile
curl -I "https://gibs.earthdata.nasa.gov/wmts/epsg4326/best/SMAP_L3_Passive_Enhanced_Day_Soil_Moisture/default/2025-06-02/2km/3/3/2.png"

# NASA catalogue metadata (no login)
curl "https://cmr.earthdata.nasa.gov/search/granules.json?short_name=GPM_3IMERGDF&bounding_box=72.5,30.9,73.6,31.9&temporal=2025-06-01T00:00:00Z,2025-06-01T23:59:59Z&page_size=1"
```

## 5. Disclosure statement for submission

> Field Shift was built by an individual participant with substantial AI coding assistance. AI was used for
> research summarisation, documentation drafting, and code scaffolding. All NASA data shown by the
> application is retrieved live from official NASA services and validated at runtime; no environmental
> values were generated by AI. Local agronomic parameters are cited to Punjab government and university
> documents, and parameters that could not be sourced are marked as unavailable rather than estimated. The
> decision engine is deterministic and its weighting is explicitly labelled as provisional.

## 6. Tools and models

- **Freebuff coding agent** — environment inspection, research, documentation, scaffolding.
- **Web search / page fetches** — official challenge page, Punjab Agriculture Department, PAU, CRS, MNFSR,
  ISRIC, NASA product documentation.
- **`pdftotext` (xpdf 4.06)** — local PDF text extraction.
- No generative model is invoked at runtime by the application.
